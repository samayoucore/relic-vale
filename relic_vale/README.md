# Relic Vale — исходный проект / source project

**Русский.** Это игровая папка Godot 4.7.2. Откройте [`project.godot`](project.godot) в редакторе и запустите сцену `scenes/Main.tscn`. Готовые Windows-версии, управление и требования описаны в [главном README](../README.md). Проверки и устройство проекта: [фаза 10](docs/PHASE_10.md), [сборка релиза](docs/RELEASE_PROCESS.md), [проверки](docs/QA_CHECKLIST.md), [производительность](docs/PERFORMANCE.md), [лицензии ресурсов](docs/ASSET_CREDITS.md). Сохранения игрока находятся в `%APPDATA%\Godot\app_userdata\RelicValePrototype\`. Отладочные тесты запускаются только в редакторской сборке; экспорт Release не принимает их аргументы.

**English.** This is the Godot 4.7.2 source project. Open [`project.godot`](project.godot) in the editor and run `scenes/Main.tscn`. See the [top-level README](../README.md) for Windows downloads, controls, and requirements. Development notes: [Phase 10](docs/PHASE_10.md), [release build](docs/RELEASE_PROCESS.md), [QA](docs/QA_CHECKLIST.md), [performance](docs/PERFORMANCE.md), and [asset licenses](docs/ASSET_CREDITS.md). Player saves are under `%APPDATA%\Godot\app_userdata\RelicValePrototype\`. Development tests run only in editor/debug builds; Release ignores their arguments.
